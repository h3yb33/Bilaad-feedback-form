# Bilaad Feedback Form

A lightweight, responsive feedback form built with HTML, CSS, and vanilla JavaScript. It collects a visitor's name, email address, and feedback message, then submits the response to a Supabase `feedback_form` table.

## Features

- Required name, email, and feedback fields
- Feedback message limited to 500 characters
- Responsive layout with Bilaad branding
- Supabase database integration
- No build step or package installation required

## Supabase setup

The form submits `name`, `email`, and `message` values to the `feedback_form` table. Create a table with matching columns in your Supabase project. For example:

```sql
create table public.feedback_form (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  message text not null,
  created_at timestamptz not null default now()
);
```

Enable Row Level Security and add an insert policy that permits anonymous form submissions. Keep the policy limited to inserts; never put a Supabase service-role key in browser code. The Supabase project URL and publishable key used by the page are configured in `scripts/script.js`.

The Supabase JavaScript client is loaded from jsDelivr in `index.html`, so an internet connection is required.

## Run locally

Serve the project directory with any static HTTP server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a browser. No compilation or installation step is needed.
